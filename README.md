## 🚀 Projects I'm proud of

### 🔥 Hearth — Your AI, your space

A local-first AI chat app with **three model experiences: Fast ⚡, Deep Think 🧠, and Unfiltered 🔓**.

- Built a **multi-model Ollama-powered chat interface**, supporting model selection, streaming responses, configurable reasoning modes, and per-chat preferences.
- Added **conversation history and search, image attachments, local settings, and privacy-minded controls** to make the experience feel like a real application.

`React` `TypeScript` `Ollama` `Local LLMs` `SQLite`

### 🤖 AI Coding Assistant + Document Q&A

- Developed a coding assistant with **DeepSeek-R1 (1.5B)** for debugging help, code suggestions, and programming questions.
- Built a **retrieval-augmented generation (RAG)** document-analysis workflow for contextual information retrieval and Q&A.

### 🤟 Signify AI — Giving gestures a voice

- Worked on an **Indian Sign Language recognition** experience using **MediaPipe hand landmarks** and neural networks for a Smart India Hackathon 2024 project.
- Collaborated with a six-member team using a **57,600-image dataset** to develop an interactive recognition system.

### 🚀 Space Y — Can this rocket land?

- Analysed historical SpaceX-related launch data to explore and predict rocket-landing outcomes as part of an IBM capstone.
- Compared **logistic regression, SVM, decision trees, and KNN** to evaluate alternative machine-learning approaches.
